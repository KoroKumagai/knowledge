# Google Cloud：個別サービス一覧

> **対象:** 2社以上で比較できる共通機能とは区別して扱うサービス・独自製品・独特の統合体系。これは独自性のある**候補一覧**であり、各社全製品の網羅・GAを保証するものではありません。

参照: [公式サービスディレクトリ](https://docs.cloud.google.com/docs/product-list)（2026-11-14時点の参照）

Google独自のデータ・AI・地理情報・Firebaseなどの製品体系を収録。一般的なIaaS/PaaSは横断表を優先。

**区分の注意:** 比較表と重複する製品は原則として掲載しません。このリストに載る製品でも、部分的な競合・他社での複合構成はあり得ます。製品の存否と採用可否は個別に確認してください。

## データ・分析

| サービス | 用途 |
|---|---|
| BigQuery Omni | 他クラウド上のBigQuery分析 |
| BigQuery Data Transfer Service | BigQueryへのデータ取り込み |
| Lakehouse（旧BigLake） | データレイクとDWHを統合するレイクハウス管理 |
| Looker | セマンティックモデルを持つBI |
| Knowledge Catalog | データ資産カタログ・ガバナンス |
| Earth Engine | 地理空間・地球観測分析 |
